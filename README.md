# ADIAN Solution & Services

**AUTOMATING TODAY • POWERING TOMORROW**

Official B2B Industrial Automation website & web application for **ADIAN Solution & Services**. Designed with modern CSS glassmorphism, responsive mobile architecture, interactive action docks, and PHP contact form handlers.

---

## 🚀 Key Features

- **Hero Section**: Dynamic industrial background with animated scanner beam video overlay and 4-diamond automated machine showcases.
- **Left Floating Action Dock**: Compact icon-only quick buttons (*Call Direct*, *WhatsApp Chat*, *Instant Quote*) on desktop that expand on hover, transitioning into a fixed bottom navigation bar on mobile devices.
- **Official Brand Assets**: High-resolution company logo, studio product renders, and interactive field engineer photo with live status indicators.
- **B2B Product Showcase**: Highlighting PLC panels, liquid dosing systems, APFC panels, MCC motor control centers, and SCADA consoles.
- **Quotations & Consultation Form**: Fully responsive single-column mobile form with PHP backend handler for direct inquiries.
- **SEO & Performance**: 100% vector FontAwesome icons, responsive media queries down to 375px, and smooth AOS scrolling animations.

---

## 🛠️ Technology Stack

- **Frontend**: HTML5, Vanilla CSS3 (Custom Design System), JavaScript (ES6+)
- **Icons & Typography**: FontAwesome 6 (SVG/Vector), Google Fonts (*Poppins*)
- **Animations**: AOS (Animate on Scroll)
- **Backend (Optional)**: PHP 8+ form handler integration
